# plantin_test_task

PlantIn Test Task is a Flutter application for a gallery that includes features such as authentication, an image gallery with lazy loading, and image uploading.

## To run the project locally

1. **Clone the repository:**

   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the project folder:**

   ```bash
   cd plantin_test_task
   ```

3. **Install dependencies:**

   ```bash
   flutter pub get
   ```

4. **Run the app:**

   ```bash
   flutter run
   ```
